# Quick Prototype Sprint - ProjexLight

## Prerequisites

- **Docker Desktop** (Windows/Mac) or **Docker Engine** (Linux)
- **Git** for version control
- **Claude Code CLI** or your preferred AI coding assistant with MCP support

## 🚀 Quick Start (3 Steps)

### Step 1: Start MCP Server

```bash
cd mcp-server
docker-compose up -d
```

Wait 30 seconds, then verify:
```bash
curl http://localhost:8766/health
```

### Step 2: Launch Your AI Coding Tool

```bash
# Navigate to project root (where .mcp.json is located)
cd ..

# Launch Claude Code (or your preferred tool)
claude
```

### Step 3: Start Coding Session

**IMPORTANT:** Once Claude Code is running, paste this command to start:

```
..claude/instructions/bootstrap.md
```

This tells Claude to read the bootstrap file which will:
- Initialize the MCP session automatically
- Show you all available tasks
- Guide you through the code generation workflow

---

## 📋 What Happens Next?

After pasting the bootstrap command, Claude will:

1. **Read the bootstrap file** and understand the project
2. **Call `projexlight_init_session`** to get your assigned tasks
3. **Show you the task list** with priorities
4. **Ask which task to start** or begin automatically

You can then:
- Let Claude generate code for each task
- Review and approve the generated code
- Move to the next task when ready

## Troubleshooting

**MCP Server not working?**
```bash
# Check health
curl http://localhost:8766/health

# View logs
docker logs projexlight-mcp

# Restart
cd mcp-server && docker-compose restart
```

**Claude not recognizing MCP tools?**
- Make sure you're in the project root directory (where `.mcp.json` is)
- Restart Claude Code after starting Docker
